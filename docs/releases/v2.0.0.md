## Arcadia 2.0.0 — interface nativa em Rust

Esta é a primeira release com a interface Desktop e Big Picture **100% nativas
em Rust/iced**. Tauri, Electron e o renderer web saíram do caminho da UI: o
processo principal agora é o próprio app nativo.

### Destaques

- **UI nativa (iced/wgpu)** — Desktop e Big Picture sem webview no processo
  principal. As fontes Inter continuam embutidas.
- **Linux: AppImage com GStreamer embutido** — o player usa a mesma versão de
  GStreamer em qualquer distro; o `AppRun` isola `GST_PLUGIN_SYSTEM_PATH_1_0`
  e `GST_PLUGIN_SCANNER`. Validação automática no CI decodifica um vídeo real
  antes de publicar.
- **Windows: zip portátil + instalador** — o setup instala por usuário em
  `%LOCALAPPDATA%\Arcadia`, cria atalhos no menu Iniciar/área de trabalho e
  inclui o runtime GStreamer. O zip continua disponível para quem prefere não
  instalar.
- **WebKit isolado** — a janela de verificação de fontes virou o binário
  separado `arcadia-source-helper`. O `arcadia-native` não linka mais
  GTK/WebKit; a UI sobe mesmo em máquinas sem a pilha do WebKit.
- **Auto-update** — `latest.yml` (Windows/NSIS) e `latest-linux.yml`
  (AppImage) publicados com SHA-512 dos artefatos.

### Requisitos e limitações

- **Linux:** o AppImage foi compilado no Ubuntu 24.04 (glibc 2.39+). É preciso
  driver gráfico com Vulkan/OpenGL e sessão X11/Wayland (wgpu).
- **Windows:** x86_64, Windows 10 ou mais novo e o Microsoft Visual C++
  Redistributable 2015–2022. O instalador não é assinado; o SmartScreen pode
  avisar na primeira execução.
- O instalador é **por usuário** (`%LOCALAPPDATA%\Arcadia`) e não pede admin.
- O helper de verificação de fontes usa GTK 3/WebKitGTK 4.1 no Linux quando a
  fonte exige desafio JavaScript; sem ele, o app e os vídeos continuam
  funcionando.

### Verificação

Baixe o `SHA256SUMS` e confira:

```bash
sha256sum -c SHA256SUMS
```
